1로그인 · 회원가입 (헤더)Header
  • Login → 로그인 페이지 → 로그인 후 보던 화면(검색 조건 그대로)으로 복귀
  • Sign Up → 회원가입 새 창
2탭 · Turnstile 위젯Tab
  • 검색 상자에 붙은 폴더 탭 · 선택한 탭만 진하게 · Item Market Price Inquiry 탭도 같은 규칙
  • 비로그인도 탭 줄 오른쪽에 Turnstile 위젯 표시 (로그인 상태와 같은 자리 · 진입 시 실행)
  • Success! 전 검색 버튼 비활성 (E4 와 같음) → Success! 후 검색 시도 → 4 얼럿 (조회 안 함)
3검색줄 (비로그인)Search
  • 진입 화면은 현행 그대로 (Stall Shop Guide) · 거래 유형 · 서버 · 검색어 입력 가능
  • 검색 버튼 · Enter → 4 얼럿 (미들서버 조회 안 함)
  • 검색 조건이 붙은 주소로 들어와도 조회 안 함 · 결과 자리는 Guide 그대로
4로그인 안내 얼럿Alert
  • 비로그인 상태에서 검색을 시도할 때마다 표시 (탭 이동만으로는 안 뜸)
  • 버튼은 OK 하나 · 문구 STALL_LOGIN_ALERT (표지 안내 ②)
5OKAction
  • OK → 바로 로그인 페이지 → 로그인 후 노점 검색으로 복귀
  • 복귀 시 탭 · 검색 조건 유지 → Turnstile Success! 후 검색 (2 화면)
6로그인 상태 헤더Header
  • 계정명 + Logout만 표시
  • Logout → 비로그인 상태(1 화면)로
7Turnstile 위젯Verify
  • 로그인 전후 모두 탭 줄 오른쪽(검색 버튼 위)에 항상 표시 · 실제 위젯 크기 300×65
  • Success! 가 떠야 검색 버튼 활성 · 확인 중에는 검색 · Enter 막음 (E4)
  • 진입 · 조회(검색 · 페이지 이동 · 상세)마다 실행 → Success! 토큰 1개로 조회 · 서버 검증
  • Cloudflare 가 요구하면 위젯 안에 체크박스 · 실패 → E2
8조회 결과 (시세 조회 예시)List
  • 결과 바(건수 · 정렬 · 개수 · 보기 전환) · 카드 구성은 현행 유지 · 거래 아이템 조회도 같은 규칙
  • 조회마다 Turnstile 검증 + 계정(AID)별 조회 수 집계 → 2차 · 3차 초과 시 이용 제한 페이지(SCR-02)로 이동 · 카드 클릭 → 상세 팝업 (내용 현행 유지 · 열 때도 Turnstile · 조회 1회)
  • 로그아웃 상태로 조회 → 1 화면으로
9페이지 이동Pager
  • 페이지당 20개 고정 (주소의 limit 값 무시)
  • 최대 50페이지 · 페이지 이동 · 정렬 · 개수 변경도 조회 1회 (Turnstile 실행 · 횟수 포함)

E2보안 확인 실패Case
  • 위젯 안 Retry → Turnstile 다시 실행 → 같은 조건 다시 조회

E3검색 결과 0건Case
  • 현행 문구 유지 · 조회 횟수에는 포함
